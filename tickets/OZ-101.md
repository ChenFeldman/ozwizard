# OZ-101 — Support new manifest format (.toml)

**Type:** Feature / Investigation
**Priority:** Medium
**Reporter:** platform-team
**Status:** Open

## Description

A couple of teams have started shipping their dependency manifests as `.toml`
instead of the JSON shape we accept today. We should "support the toml ones too."

Came up unexpectedly — not sure how widespread it is yet.

## Notes

- Not clear which TOML layout they're using; get a real example before coding.
- Should the ecosystem be inferred from the file, or still passed explicitly?
- Do transitive deps show up in these files or not?

## Acceptance

- We can ingest the new format end to end.
