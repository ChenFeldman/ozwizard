# OZ-102 — Parallelize dependency scan for large/complex artifacts

**Type:** Feature / Performance
**Priority:** Medium
**Reporter:** perf
**Status:** Open

## Description

Scanning a big artifact (lots of transitive deps) feels slow. It looks like we
process dependencies one after another. Can we do them in parallel so large
artifacts don't take so long?

## Notes

- Someone mentioned the scan does an upstream advisory lookup per dependency.
- Watch out for changing the results — same findings, just faster.

## Acceptance

- Scans of large artifacts are noticeably faster.
- Existing scan behavior/verdicts unchanged.
