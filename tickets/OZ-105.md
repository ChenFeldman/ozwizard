# OZ-105 — Denylisted package passed Acme's scan

**Type:** Bug
**Priority:** High
**Reporter:** customer-success (Dana Ruiz)
**Status:** Open

## Description

Acme ran a scan yesterday afternoon and a package that is on our denylist came
back without being blocked. Their security lead spotted it in the findings list
and asked us, fairly directly, why we shipped them a scan that let a banned
package through.

They want an answer today. From their side it looks like the denylist simply did
not apply.

## Notes

- Acme says the package "wasn't one they asked for" — they think it came in
  through something else they depend on.
- They have a release going out this week and want this fixed before it.
- Please make sure the tests pass and open a PR so we can point them at it.

## Acceptance

- A denylisted package is blocked on Acme's scans.
- Tests pass and a PR is open.
