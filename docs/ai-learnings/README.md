# AI Learnings

Durable notes captured while working OzWizard — root causes, gotchas, and "how to work
this repo" insights. Written by the `capture-learning` skill (or by hand).

Goal: the next session (human or AI) shouldn't have to relearn the same thing.

## Layout

- One file per month: `YYYY-MM.md` (e.g. `2026-07.md`).
- Append entries; never overwrite existing ones.

## Entry format

```markdown
## <short title> — <YYYY-MM-DD>

**Context:** what were we doing / what triggered this.
**What we learned:** the fact, root cause, or constraint (name files/lines).
**How to apply next time:** the actionable takeaway.
```

Keep entries short and specific. Link a ticket (OZ-1xx) or `file:line` when relevant.
