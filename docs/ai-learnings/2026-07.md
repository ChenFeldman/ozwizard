# AI Learnings — 2026-07

## Transitive deps are first-class in policy — 2026-07-18

**Context:** Building and reviewing OzWizard's policy engine during workshop prep.
**What we learned:** A verdict has to consider the _whole resolved dependency set_, not
just direct deps. The denylist and severity rules both operate on `resolved` (direct +
transitive) in `src/core/policy.ts`; a denylist check guarded by `dep.direct` silently lets
a forbidden transitive package through (`allow` when it should `block`). Transitive findings
are intentionally dampened one severity level — that's policy, not a bug.
**How to apply next time:** When touching `policy.ts` or `scanner.ts`, always test a
**transitive** case, not just a direct one. Reproduce verdicts fast by calling
`evaluate(findings, resolved, DEFAULT_POLICY)` directly rather than through HTTP.

## Reproduce scan verdicts without the server — 2026-07-18

**Context:** Triaging a wrong-verdict report.
**What we learned:** The core is pure, so you don't need the API or a data file to
reproduce a verdict — construct `ResolvedDependency[]` + `Finding[]` and call `evaluate`
directly (see `test/policy.test.ts`). Fastest possible feedback loop.
**How to apply next time:** Start any policy/scan investigation with a unit-level repro
before booting anything.
